# Users onboarding API (backend)

Users Onboarding API is an EBSI core service to enable users (Natural Persons and Legal Entities) to onboard on EBSI Pre-prod and get an "entry ticket" to get access to the protected EBSI resources.

For more information see:

- [Technical Specifications](https://ec.europa.eu/digital-building-blocks/wikis/x/koXkFQ)
- API catalogs:
  - [EBSI Pre-production network API Catalog](https://api.preprod.ebsi.eu/docs)
  - [EBSI Production network API Catalog](https://api.ebsi.eu/docs)

## Service configuration

Create a `.env.default.local` file locally. You can duplicate the content of `.env.default` or only set the necessary variables.
